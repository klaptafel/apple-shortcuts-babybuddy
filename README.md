# apple-shortcuts-babybuddy
An Apple Shortcuts collection to add data to Baby Buddy.

> [!NOTE]
> The Shortcuts are in Dutch. It's probably easy to translate. If you do so, feel free to PR. 

**Parent shortcut:**
- Baby Buddy

- Slaap
- Voeding
- Luier
- Prijs checken
