# Apple Shortcuts - Baby Buddy
An Apple Shortcuts collection to add data to [Baby Buddy]([url](https://github.com/babybuddy/babybuddy)).

> [!NOTE]
> The Shortcuts are currently only available in Dutch. It's probably easy to translate. If you do so, feel free to PR. 

**Main shortcut:**
- Baby Buddy

**Child shortcuts:** 
- Sleep
- Feeding
- Diaper
- Check prices
- Vitamine K check
- Statistics

## Getting started
I advise you to install all child shortcuts first, otherwise the main one will not be able to find all childs and you would have to select them manually. It's multiple shortcuts by the way because that way tweaking was a bit easier 😉

### Setup
When importing the main shortcut it will ask you for your local Baby Buddy URL and API key, select your child (if needed), your Home Asisstant Server (in order to get the notifications to work) and optionally to choose your baby monitor app.
